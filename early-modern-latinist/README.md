# Early Modern Latinist

Public project page for the COMHIS Early Modern Latinist research agent.

The page is deliberately a synthesis rather than a publication of the working
corpus. It contains no licensed scans, private source paths, restricted data,
training prompts, or copyrighted critical-edition text.

## Local preview

From the repository root:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080/early-modern-latinist/`.

## Publication

The organization Pages repository publishes the `master` branch at
`https://comhis.github.io/`. This page is served from
`https://comhis.github.io/early-modern-latinist/`.
